# Ô Ăn Quan – Trung Thu

Game dân gian **Ô ăn quan** phiên bản web, kết hợp không khí **Tết Trung Thu** (trăng, đèn lồng, sân đình...) làm điểm đặc biệt.

## Chạy thử

Mở trực tiếp `index.html` bằng trình duyệt, hoặc bật server tĩnh bất kỳ:

```bash
python3 -m http.server 8000
# rồi mở http://localhost:8000
```

## Công nghệ

Toàn bộ game nằm gọn trong một file `index.html` (HTML/CSS/JS thuần, không cần build).
